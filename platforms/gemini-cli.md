# Gemini CLI

Gemini CLI supports Agent Skills and can install them from Git repositories.

```bash
gemini skills install https://github.com/nixxx00133-svg/obsidian-card-knowledge.git
```

Check discovery with `/skills list`. Invoke the skill by asking for a card and knowledge-base synthesis or by activating the discovered skill. Local file writing depends on the CLI's access to the chosen Obsidian vault.

Official guide: https://geminicli.com/docs/cli/skills/
