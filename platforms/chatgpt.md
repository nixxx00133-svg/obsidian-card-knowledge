# ChatGPT

ChatGPT has an uploadable Skills feature on eligible accounts and workspaces. Availability depends on product, plan, and workspace settings. Download this repository and upload the skill through the Skills interface if the feature is available to you.

A Skill supplies reusable workflow instructions; it does not by itself grant access to a local Mac filesystem. If the active chat surface has no connected tool that can write to your Obsidian vault, ask the model to return each note as Markdown, then save the files into the corresponding folders yourself.

Official guide: https://help.openai.com/en/articles/20001066-skills-in-chatgpt
