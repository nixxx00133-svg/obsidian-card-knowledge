# Claude Code

Claude Code supports Agent Skills and loads personal skills from `~/.claude/skills/<skill-name>/SKILL.md`.

Install this repository:

```bash
git clone https://github.com/nixxx00133-svg/obsidian-card-knowledge.git ~/.claude/skills/obsidian-card-knowledge
```

Invoke with `/obsidian-card-knowledge`. For automatic invocation, Claude Code uses the skill description to decide when it is relevant. Local file writing still depends on Claude Code's access and permissions for the chosen vault.

Official guide: https://code.claude.com/docs/en/skills
