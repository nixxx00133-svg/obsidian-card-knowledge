# Codex

Codex reads this Agent Skill from its skill directory. Install the repository with the Codex skill installer, or copy its contents to `~/.codex/skills/obsidian-card-knowledge/`.

Invoke it explicitly with `$obsidian-card-knowledge`, or ask for card and knowledge-base synthesis after a discussion. Local file writing works only when the active Codex environment can access the selected Obsidian vault.

Official guide: https://developers.openai.com/plugins/build/skills
