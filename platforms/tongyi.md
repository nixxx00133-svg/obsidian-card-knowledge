# 通义 / 千问适配

## 适用入口

本文把“通义”分成消费者使用的通义/千问对话产品，以及面向开发者的阿里云百炼。二者的自定义能力和本地文件访问不是一回事。百炼官方提供智能体应用，可将模型与工具、知识库连接；这不代表普通通义聊天能访问本地 Obsidian。

## 通义/千问普通对话或自定义助手

1. 如果客户端提供自定义智能体/助手入口，可将根目录 `SKILL.md` 作为角色指令或知识材料；如果没有稳定的自定义入口，就在整理前把 `SKILL.md` 粘贴或上传到当前会话。
2. 提供卡片目录、知识库目录及现有文件名，以便生成可靠的 Obsidian 链接。
3. 说“生成卡片和知识库”。
4. 没有本地文件访问工具时，要求分别输出 Markdown 文件，不要让模型声称已写入 vault。

## 百炼开发者入口

可在百炼控制台创建智能体应用，把本仓库规范作为系统指令/应用知识材料，并按需配置文件或知识库工具。若需要自动写入本机 Obsidian，仍需另外提供安全、明确授权的本地文件工具或同步流程；百炼智能体本身不因部署在云端就能直接访问个人电脑目录。
