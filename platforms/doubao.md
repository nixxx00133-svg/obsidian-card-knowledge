# 豆包适配

## 适用入口

本文面向豆包网页端/客户端的普通对话和自定义智能体。豆包官方介绍支持创建和定制智能体，可设置说话风格、技能和背景；这不等同于把 GitHub 上的 `SKILL.md` 目录原样安装为本地 Agent Skill。

## 设置方法

1. 打开豆包的智能体创建/定制入口，创建一个仅自己使用的助手。
2. 将仓库根目录的 `SKILL.md` 内容作为指令或知识材料加入。如果当前入口不接受完整文件，粘贴下方“快速启动指令”，并在需要整理时把 `SKILL.md` 上传/粘贴到当前对话。
3. 明确告诉它你的 Obsidian 卡片目录和知识库目录。
4. 完成讨论后说“生成卡片和知识库”。

### 快速启动指令

> 请遵循我提供的 Obsidian Card and Knowledge 规范。只有我明确说“生成卡片和知识库”或“整理卡片和知识库”时，才整理本次对话中自上次整理以来的内容。卡片和知识库长文分开输出，使用规范中固定的结构、YAML 和 Obsidian 双向链接。先检查内容、组件、文件名与链接目标；不要声称写入本地文件，除非当前对话确实提供并使用了文件写入工具。没有本地文件工具时，分别输出可保存的 Markdown 文件内容，并标明建议文件名。

## 本地 Obsidian 写入

普通聊天或自定义智能体不能仅凭提示词访问电脑上的 Obsidian vault。没有明确的本地文件连接器/授权写入工具时，要求豆包给出 Markdown 文件内容，再手动保存。上传资料或让模型记住规则，都不代表它能写本地文件。
